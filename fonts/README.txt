Atkinson Hyperlegible (SIL Open Font License) - self-hosted so nothing loads from a third party.

Put these three files in this folder:

  atkinson-hyperlegible-latin-400-normal.woff2
  atkinson-hyperlegible-latin-400-italic.woff2
  atkinson-hyperlegible-latin-700-normal.woff2

A free source for woff2 files: https://fontsource.org/fonts/atkinson-hyperlegible (Download button).
If the downloaded file names differ, edit the three url(...) lines at the top of style.css to match.
Until the files are added, the page uses your device's default sans-serif font and still works.
